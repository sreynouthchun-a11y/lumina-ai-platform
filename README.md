# Lumina AI Platform

Lumina AI is a premium, production-ready landing page for a modern AI technology company. 

## 🚀 Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Components**: Custom implementation inspired by shadcn/ui patterns

## 🛠️ Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sreynouthchun-a11y/lumina-ai-platform.git
   cd lumina-ai-platform
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open the browser**:
   Visit `http://localhost:3000`

## 🌐 Deployment

The project is optimized for Vercel. To deploy:
1. Push your code to GitHub.
2. Import the repository into Vercel.
3. Deploy.
